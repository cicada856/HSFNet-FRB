# Matched Simulation-Only DLSR Control

This directory contains the matched control for the CHIME-adapted DLSR.
Start with summary.md and paired_statistics.md.

The experiment ran on an NVIDIA L20 GPU with seeds 42, 43, and 44. Per-sample
predictions, probabilities, confusion matrices, paired tests, the locked
protocol, and reproduction code are included. Trained component and router
weights remain on the research server and are not included in this release.
